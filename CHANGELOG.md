# Changelog

## Unreleased

The first prototype.

### Added

- Images of several layers with opacity and 14 blend modes; open in tabs.
- History of the changes with undo, redo and a click on a step.
- Selections: rectangle, ellipse, lasso, magic wand; union, exclude,
  intersect and xor; moving the selected pixels or the outline.
- Tools: paintbrush, eraser, pencil, paint bucket, gradient, color picker,
  clone stamp, text, line, shapes, zoom, pan.
- Image: resize, canvas size, crop to selection, flip, rotate, flatten.
- Seven adjustments and eight effects, shown on the image while their
  parameters change.
- Files: PNG, JPEG, BMP, GIF, TIFF, WebP (open only) and the layered
  `.apn`; the clipboard of the system on Windows, Linux (xclip,
  wl-clipboard) and macOS.
- Light and dark themes, English and Russian.
- One running copy: a second start opens its files in the first one.
- Windows self-install, Linux packages and installer script, macOS dmg,
  as in the other AltBins utilities.
